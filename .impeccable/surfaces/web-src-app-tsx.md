# Dunvex admin panel

Scope: the whole operator panel (login, overview, users, protocols, settings). Mode: Operate.
Audience: VPN operators, Persian-first, often on a phone. Job: add/renew users, share configs, watch usage and server health.
Constraints: fa (RTL) + en; concise copy; every number real; no invented claims. Unattended run: direction taken from the roll's assignment (no interview; inferred from the brief).

## Direction contract
THESIS: The server is an interchange and every protocol is a coloured line leaving the country; the panel reads like a night metro map, refusing the grey card-grid admin template.
OWN-WORLD: Midnight-enamel blue ground and rail, porcelain-white type, four line inks (scarlet Reality, cobalt CDN, amber UDP/QUIC, green classic) used as data colours; station ticks and interchange rings as the only ornament; Fira Sans + Vazirmatn with tabular figures.
STORY: The operator sees at once which lines are open, how much is flowing and who is online, then acts on a user in one or two taps.
