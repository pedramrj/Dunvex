# Dunvex logo

`dunvex-logo.png` is the owner-approved Dunvex logo (Pedram), copied byte for
byte from the previous Dunvex project (`assets/branding/dunvex-logo-approved-v2.png`).

- 1254 × 1254, 8-bit RGBA with transparent corners, 1,097,444 bytes
- SHA-256 `3055b8b56c3b1da83c29b683fc85bdcdb2d2bb64c988b4f1c3ce27c66798adee`

The panel uses the uniform-scale derivatives from that project in `web/public/brand/`
(512 px logo, 64 px favicon, 180 px Apple touch icon, 192 px app icon). Parts of
the logo (emblem, wordmark, "Powered by Pedram") are shown through CSS viewports
over the same square image; nothing is cropped, redrawn or recoloured.
